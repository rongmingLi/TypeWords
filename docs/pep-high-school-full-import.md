## 3. 数据规范与质量保障
所有 2,221 个词条均严格遵循 TypeWords 词库标准：
1. **纯正英美音标**：`phonetic0`（英音）与 `phonetic1`（美音）采用权威国际音标（IPA）。
2. **规范词性释义**：`trans` 采用标准格式 `[{"pos": "...", "cn": "..."}]`。
3. **适龄双语例句**：
   - 例句优先选取自柯林斯高阶英语词典及优质双语语料库。
   - 严格过滤暴力、枪支、战争、涉政、不良习气等不适合中学生的语境，保证例句健康、积极、自然。
4. **纯正英文近义词**：`synos.ws` 经过严格正则表达式校验，仅包含纯英文字符，杜绝乱码、德语字符或中文残留。
5. **派生词与衍生词**：`relWords` 整理了词根及不同词性（名词、形容词、副词、动词）下的衍生词组。
6. **课文出处标记**：`etymology` 清晰标注教材册别与对应单元（如 `普通高中教科书·英语必修第一册，Unit 1`）。
