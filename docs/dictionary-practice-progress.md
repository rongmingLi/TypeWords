# 词典练习进度

首页的已学数量在整组结算后更新；未完成任务单独保存单词位置、任务词表、练习阶段和计时数据。

未完成任务按当前本地用户及词典标识保存到 IndexedDB。切换词典时保留原任务，切回时恢复；完成任务或主动重置练习只清除当前词典的任务。重置用户学习数据或删除本地用户时也会删除对应的任务存档。

兼容旧版共用缓存：首次切换前将旧任务归属到原词典。以前已经被清除的任务无法通过此修复找回。

这些独立任务存档保存在当前浏览器内。现有远端同步和导出仍只携带当前的共用任务槽位，不代表所有词典的未完成任务均可跨设备恢复。

回归检查：

1. 在词典 A 中推进至少一个词，但不完成整组。
2. 切到词典 B，推进至少一个词。
3. 切回 A，确认单词位置和阶段保持不变。
4. 刷新练习页，确认仍能恢复。
5. 检查已结算的首页进度未被切换操作清零。

自动化基础检查：`npm run test:unit`、`npm run build`。
